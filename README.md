# Credit Card Fraud Detection Project

This is my final project for DS325: Applied Data Science (Spring 2025) with Professor Roth. The goal of this project is to use machine learning models to detect fraudulent credit card transactions based on real-world data.

## Project Summary

We trained and evaluated two classification models—Logistic Regression and Random Forest—using both undersampling and SMOTE to handle class imbalance. Our results show that Random Forest with SMOTE performed best at identifying fraud with minimal false positives.

## Dataset

We used the **Credit Card Fraud Detection dataset** from Kaggle:  
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

⚠️ The dataset is not included in this repository due to GitHub’s file size limits. Please download it directly from the Kaggle link above if you'd like to run the notebook.
